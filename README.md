# PixelNorte
PixelNorte es una página web desarrollada para la materia Laboratorio Full Stack I.
Presenta una empresa dedicada a soluciones digitales y desarrollo web, mostrando sus
servicios, información institucional y canales de contacto mediante una interfaz
moderna, responsive y fácil de navegar.

## Tecnologias
 HTML5- CSS3 (Flexbox, Grid, Mobile First)
